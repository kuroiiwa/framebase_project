# iCloud 运行诊断日志

云端删除、确认前复核和 Apple 会话验证自动生成逐次诊断日志，无需手动打开 debug 开关。

## 查看与反馈

1. 删除/复核的进度面板，以及会话验证结果旁，会显示日志编号、绝对路径和下载按钮。
2. `/icloud` 页的“运行诊断日志 · 查看地址与下载”可查看当前用户近期日志。刷新列表即可找到刚结束的操作；刷新页面或重启后端不会删除已有日志。
3. 反馈问题时附上对应 `.log` 文件，并描述所点的操作、预期结果和实际结果。

日志保存在项目目录下的 `.framebase-icloud/<FrameBase用户名>/logs/<日志编号>.log`，已经被 Git 忽略。下载接口要求登录，按当前用户隔离，不接受任意文件路径。每个用户保留最近 30 份，每份约 1 MB 上限，旧日志自动清理。

## 内容

日志采用 JSON Lines：每行包含时间、事件和数据。记录应用版本、提交号、Node/平台、任务编号、预览或正式删除、目标文件及匹配元数据、执行阶段、扫描进度、工具路径/版本、退出码/信号、机器错误原因、异常名称和调用位置，以及最终状态和耗时。

不保存 Apple 密码、验证码、Cookie、会话令牌或完整环境变量；不保存可能回显登录凭据的原始 PTY 输出。工具输出仅提取结构化错误、异常名称和调用位置。日志包含照片名称、资产编号和本地路径，分享前可按需要检查这些信息。

日志写入失败会在操作面板显示提示，不影响删除任务自身的结果。部署后需要重启 FrameBase 后端生效；等待已有 iCloud 任务结束后再重启。
